# Evidence

This directory contains the evidence collected during the Windows Log Analysis & Incident Investigation project.

The evidence supports the investigation of Windows authentication and Remote Desktop activity through relevant Windows Event IDs and security-event data.

## Evidence Files

### 01 — Failed Logons

Shows Windows Event ID `4625` failed authentication activity identified during the investigation.

### 02 — Successful Logon

Shows Windows Event ID `4624` successful authentication activity identified during the investigation.

### 03 — RDP Authentication

Shows Windows Event ID `1149` successful Remote Desktop authentication activity, including the associated account and source network address.

### 04 — Windows Security Event Dataset

Shows the Windows Security Event Log dataset used as the source for authentication-event analysis.

## Purpose

These evidence files provide visual support for the investigation methodology, event correlation, timeline analysis, findings, and response recommendations documented in the project.
